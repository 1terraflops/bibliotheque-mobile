# bibliotheque 📚

bibliotheque is a book tracking app where users can manage their digital library, log reading sessions, view reading statistics, write reviews and track their reading trends across their entire library.

If you are looking for technical documentation, check the [docs folder](docs/). Start with the [overview](docs/overview.md).

### Adding Books via ISBN & Barcode
Users can add books to their library by scanning a bar code with their camera or searching an ISBN. After that, they can check out more info about the book and add it to their library.

## Overview of Capabilities

bibliotheque includes additional features that are not listed in this document. If you are interested to check out the full app, visit [setup](docs/setup.md) file in [docs folder](docs/).

### Core features covered in this document:

* **ISBN & Barcode Scanning:** Users can add books to their library by typing an ISBN or scanning a bar code.
* **Book Information Preview:** Users can check out more info about each book before saving it to their collection.
* **Library:** Organises books across In Progress, Not Started, Completed, Dropped and Favourites categories.
* **Session Tracking:** Users can track their reading progress using sessions with start/end page logging.
* **Rich Logs & Stats per Book:** Sessions provide rich logs and stats per book with visualisation via charts.
* **Reading History:** Users can check their chronological reading history on Activity tab.
* **Catalog Search:** Users can search books in the search tab and view more details about the books along with reviews from other users.
* **User Reviews:** Users can review books and flag reviews that contain spoilers.
* **Profile Tab:** On the profile tab, users can view their reading trends across all their library and reviews.
* **Light Mode:** Full light mode support alongside the dark theme.
